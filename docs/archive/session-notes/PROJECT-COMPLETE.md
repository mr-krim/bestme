## How to Use

### Quick Start
```bash
# Clone and build
git clone https://github.com/yourusername/bestme.git
cd bestme
cargo tauri dev

# Or download pre-built from releases
```

### Distribution
```bash
# Create packages for distribution
./scripts/package.sh
```

### Testing
```bash
# Run all tests
cargo test

# Run with coverage
cargo tarpaulin
```
